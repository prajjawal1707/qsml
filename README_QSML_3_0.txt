QSML 3.0 — Release overview
===========================

QSML is a classical quantum-inspired search and optimization project.

Version milestones:
2.6 Experiment persistence with SQLite.
2.7 Binary equality and at-most constraint penalties.
2.8 Max-Cut and knapsack QUBO problem builders.
2.9 A unified Python API.
3.0 Import and environment release checks.

This release does not implement physical qubits and does not establish
quantum advantage. GPU acceleration is classical GPU computation.

The 15 added tests cover the new modules. They should be run together
with the existing 35 tests using the project's single launcher.
